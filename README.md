# Expense Tracker 🧾

A simple command-line application built with Python that helps users record their expenses and calculate their total spending.

## Features

* Add new expenses with a name and amount.
* View all recorded expenses.
* Calculate the total expenses.
* Navigate through an interactive menu.gi
* Exit the application whenever needed.

## Technologies Used

* Python
* Lists and Tuples
* `while` loops
* Conditional statements (`if`, `elif`, `else`)
* `for` loops
* User input handling

## Requirements

* Python 3 installed on your computer.

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR-REPOSITORY-URL
   ```

2. Open the project folder.

3. Run the program:

   ```bash
   python expense_tracker.py
   ```

   Replace `expense_tracker.py` with your actual Python filename if it is different.
